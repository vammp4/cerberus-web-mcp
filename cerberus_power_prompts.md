# ⚡ Cerberus Web MCP — Промпти та інструкція використання

> **Для кого:** Всі хто хоче зробити агента розумнішим у роботі з вебом — без зайвих налаштувань.  
> **Куди вставляти промпти:** В Claude Code, Cursor, Windsurf, Antigravity — будь-куди де є Cerberus MCP.

---

## 🚀 З чого почати (перші 5 хвилин)

Cerberus — це твій особистий веб-агент всередині ШІ. Він вміє три речі:

| Команда | Що робить | Коли використовувати |
|---|---|---|
| `cerberus_query` | Шукає в інтернеті або читає сторінку | **Завжди** — для будь-якого пошуку або URL |
| `cerberus_social_probe` | Читає YouTube, GitHub, Reddit, Twitter | Коли є конкретне відео, репо або гілка |
| `cerberus_breach_prep` | Обходить Cloudflare і захищені сайти | Коли сайт блокує або вимагає перевірку |

### Твій перший промпт (спробуй прямо зараз)

Просто напиши агенту:

```
Використай cerberus_query щоб знайти [будь-яка тема] і дай мені резюме.
```

Або:

```
Прочитай цей сайт через cerberus_query: [вставити URL]
```

**Це все.** Агент сам розбереться з рівнями, таймаутами і захистом.

## 🔍 ГОЛОВА 1 — РОЗВІДКА: Пошук і читання сайтів

### Прочитати та проаналізувати сторінку
```
Використай cerberus_query для читання: [URL або тема для пошуку]

Витягни і структуруй:
1. Головна ідея / аргумент сторінки
2. Конкретні дані: числа, дати, факти
3. Хто автор і наскільки джерело надійне
4. Що недомовлено або суперечить собі

Кожне твердження — з точною цитатою, не переказом.
```

---

### Порівняти конкурентів (5 штук за раз)
```
Використай cerberus_query і по черзі прочитай ці 5 сайтів:
[URL1], [URL2], [URL3], [URL4], [URL5]

Для кожного витягни:
- Ціни і тарифи
- Головний заголовок (що обіцяють)
- На кого орієнтуються
- Слабкі місця, що видно зі сторінки

Потім зроби порівняльну таблицю: Параметр | Сайт1 | Сайт2 | Сайт3 | Сайт4 | Сайт5
```

---

### Дослідити тему по кроках
```
Тема для дослідження: [ТЕМА]

Крок 1: cerberus_query("[ТЕМА] огляд 2025") — знайди топ-3 джерела
Крок 2: Прочитай кожне джерело через cerberus_query(url)
Крок 3: Знайди суперечливу думку: cerberus_query("[ТЕМА] критика проблеми")
Крок 4: Зведи все в структурований бриф з посиланнями

Ліміт токенів: не більше 2000 на одне джерело — використовуй параметр focus.
```

---

### Стежити за оновленнями бібліотеки або фреймворку
```
Я працюю з [НАЗВА БІБЛІОТЕКИ]. Використай cerberus_query:

1. Прочитай офіційний changelog: [DOCS_URL]
2. Знайди breaking changes за останні 3 версії
3. Перевір GitHub: cerberus_social_probe("github", "[org/repo]", "read")

Позначай все, що може зламати мій поточний код.
```

---

### Читати тільки потрібну частину (економія токенів)
```
Використай cerberus_query("[URL]", focus="[КЛЮЧОВЕ СЛОВО]")

Мені потрібна тільки секція про [ТЕМА]. Навігацію, футери, рекламу — ігнорувати.
Поверни не більше 800 токенів найрелевантнішого контенту.
```

> 💡 **Порада:** `focus=` — найважливіший параметр. З ним агент читає в 5–10 разів менше токенів і дає точнішу відповідь.

## 🎯 ГОЛОВА 2 — ЗОНД: Закриті платформи

### YouTube — Субтитри і аналіз відео
```
Використай cerberus_social_probe(platform="youtube", target="[URL відео]", action="subtitle", lang="uk,en,en-orig")

Після отримання транскрипту:
1. Таймстемпований план (де що відбувається)
2. Всі конкретні твердження з числами
3. Список дій (numbered list)
4. Найважливіший 60-секундний фрагмент
5. TL;DR в 3 реченнях
```

---

### YouTube → Пост або стаття
```
Використай cerberus_social_probe щоб отримати субтитри: [URL]

Перетвори транскрипт на:
- Статтю (800 слів, редакційний стиль)
- Twitter-тред (15 твітів: хук → інсайти → заклик до дії)
- LinkedIn-пост (300 слів, ділова подача, конкретні дані)

Зберігай оригінальні приклади і метафори спікера.
```

---

### GitHub — Розбір чужого репо
```
Використай cerberus_social_probe(platform="github", target="[URL репо]", action="read")

Проаналізуй:
1. Архітектурні патерни
2. Вибір залежностей і ризики
3. Якість коду: тести, обробка помилок
4. Відкриті issues — що болить у користувачів
5. Ліцензія і умови використання

Порівняй з моїм стеком і вкажи на несумісності.
```

---

### Reddit — Що думає цільова аудиторія
```
Використай cerberus_social_probe(platform="reddit", target="[URL або subreddit]", action="read")

Витягни:
1. Повторювані скарги і болі
2. Запити на функції (більше одного разу)
3. Точні фрази якими люди описують проблему (мова клієнта)
4. Хто відповідає — експерти чи новачки
5. Рекомендовані рішення з причинами

Формат: Болі | Бажані рішення | Словник аудиторії
```

---

### Розвідка по всіх платформах одночасно
```
Зроби 360° дослідження [ТЕМА / ПРОДУКТ / ПЕРСОНА]:

1. cerberus_social_probe("youtube", "[назва]", "subtitle") — відео-контент
2. cerberus_social_probe("github", "[org/repo]", "read") — технічна репутація
3. cerberus_social_probe("reddit", "[subreddit]", "read") — думка спільноти
4. cerberus_query("[назва] site:twitter.com") — публічні пости

Зведи у розвідувальний бриф: що говорять, де критикують, де хвалять.
```

## 🔥 ГОЛОВА 3 — ЗЛОМ: Cloudflare і захищені сайти

### Обійти захист і зчитати дані
```
Крок 1: Використай cerberus_breach_prep(url="[URL з Cloudflare]") щоб вирішити challenge.
Крок 2: Запам'ятай шлях до storageState.json з відповіді.
Крок 3: Передай цей шлях у Playwright MCP для навігації без CAPTCHA.

Мета: [що треба зробити на цьому сайті]
```

---

### Заповнити форму або зареєструватися
```
Використай cerberus_breach_prep("[URL]") щоб обійти bot-detection.
Потім через Playwright MCP:
1. browser_navigate до [URL]
2. browser_fill_form з полями: {поле: значення}
3. browser_click на кнопку submit
4. browser_screenshot для підтвердження
5. browser_network_requests — захопи відповідь API

Поверни отримані дані.
```

## 🛡️ СИСТЕМНИЙ ПРОМПТ (вставляй в AGENTS.md)

### Короткий варіант
```markdown
## Правила роботи з вебом
- ОСНОВНЕ: cerberus_query — для будь-якого пошуку або читання URL
- ПЛАТФОРМИ: cerberus_social_probe — YouTube, GitHub, Reddit, Twitter
- CLOUDFLARE: cerberus_breach_prep + Playwright MCP — для захищених сайтів
- LEGACY: claude-in-chrome або curl — тільки якщо явно попросив користувач
- ТОКЕНИ: завжди вказуй focus="[термін]" при читанні великих сторінок
```

---

### Повний варіант
```markdown
## Протокол веб-операцій — Cerberus Engine

P0 — cerberus_query(query_or_url, focus):
  Запускати: будь-який пошук, читання документації, URL у повідомленні
  Завжди використовуй focus для цільового витягу. Макс. 1500 токенів на fetch.

P1 — cerberus_social_probe(platform, target, action):
  Запускати: YouTube, GitHub, Reddit, Twitter
  Дії: "subtitle" | "read" | "metadata"
  Мова для YouTube: "uk,en,en-orig"

P2 — cerberus_breach_prep(url) → потім Playwright MCP:
  Запускати: Cloudflare challenge, сайти за логіном, інтерактивні форми
  Зберігай storageState для повторних Playwright-запитів

P3 — Застарілі інструменти (claude-in-chrome, curl):
  Тільки якщо явно попросив користувач або всі вище не спрацювали
  Ніколи не запускати автономно

### Дисципліна токенів
- Не читай цілу сторінку якщо вистачить фокусного витягу
- Підсумовуй після кожного fetch — не накопичуй сирий контент
- Якщо контент > 2000 токенів — витягуй тільки релевантну секцію
- cerberus_query дешевша за скриншоти у 10–50 разів
```

## 💡 Шпаргалка: 6 прийомів на щодень

| Прийом | Що писати |
|---|---|
| **Точне читання** | Додай `focus="ціни"` або `focus="API"` — в 5–10х менше токенів |
| **Паралельний пошук** | "Прочитай ці 4 URL по черзі і порівняй" |
| **Ланцюг Scout → Probe** | Спочатку `cerberus_query` для пошуку, потім `cerberus_social_probe` для глибини |
| **Breach → Playwright** | `cerberus_breach_prep` один раз — далі Playwright без обмежень |
| **Без галюцинацій** | "Кожен факт — з URL джерела" — агент перестає вигадувати |
| **Бюджет токенів** | "Ліміт: 3000 токенів на все дослідження" — агент стає точнішим |
